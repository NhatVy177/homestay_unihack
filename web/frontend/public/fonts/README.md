# Font trang chủ

`playfair-display-700.ttf`: Playfair Display, weight 700, dùng riêng tiêu đề trang chủ để theo kiểu chữ của trang tham khảo. Nguồn Google Fonts: https://fonts.google.com/specimen/Playfair+Display (tải ngày 2026-11-17 qua CSS API). Font được lưu local, hỗ trợ dấu tiếng Việt; các trang nghiệp vụ vẫn dùng Lexend/Inter.

Giấy phép: SIL Open Font License, bản sao trong `OFL-PlayfairDisplay.txt`, lấy từ https://github.com/google/fonts/blob/main/ofl/playfairdisplay/OFL.txt.
