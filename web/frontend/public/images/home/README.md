# Ảnh minh họa trang chủ

Tải lại các ảnh Unsplash vốn đã được tham chiếu trong `TrangChu.jsx`/`TrangChu.css`, để phần hero, thư viện ảnh, giới thiệu và ảnh dự phòng hoạt động từ asset local. Đây là ảnh minh họa không gian, không phải ảnh xác minh của các chi nhánh. Ảnh phòng do API trả về vẫn được ưu tiên; lỗi tải ảnh dùng ảnh dự phòng theo loại phòng.
